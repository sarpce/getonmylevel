# Context tools

| Approach | Strengths | Costs and limits | When it fits |
| --- | --- | --- | --- |
| Targeted `rg` and file reads | No indexing dependency; fast to start and easy to inspect. | Repeated searches can cost time; text search does not provide semantic references or type-aware relationships. | Small projects, one-off changes, and focused questions. |
| Existing CodeGraph | Can return relevant symbols, relationships, and line-numbered source when the environment provides it. | Availability, query interface, refresh behavior, and index coverage vary. Indexing locally does not mean content sent to a model is private from the configured service. | The GUI installer offers CodeGraph independently for Codex and Claude Code. If selected, its integration configures the chosen client globally; it does not initialize projects. Use CodeGraph when installed and useful; fall back to `rg` if unavailable, stale, or unhelpful. See [CodeGraph](https://github.com/colbymchenry/codegraph). |
| Graphify | Builds a graph from code and can extract semantic relationships from documentation and other media. | Adds setup, rebuild, and storage costs. Its documentation says code-only extraction can run locally, while documentation and media may be sent to a configured assistant or backend. Check current behavior and privacy terms before use. | Consider only when mixed-media coverage or graph queries provide a demonstrated benefit beyond existing indexes. See [Graphify](https://github.com/Graphify-Labs/graphify). |
| Language server or AST index | Definitions, references, types, and syntax-aware navigation can be precise. | Language and server coverage vary; setup and freshness need maintenance. See the [Language Server Protocol](https://microsoft.github.io/language-server-protocol/). | Reuse one already configured for the project's languages and task. |
| Project documentation and a compact local summary | Captures human architectural intent and cross-cutting responsibility that symbol tools may not infer. | Requires careful maintenance and can become stale. | Add only when recurring navigation justifies upkeep; keep source links and uncertainty explicit. |

Prefer existing CodeGraph when available and relevant, paired with targeted search. Add a small summary for architectural intent not already captured. Do not install Graphify or another dependency by default. If using the terminal skill-copy fallback, CodeGraph is not installed; set it up separately through the GUI or upstream instructions. Project indexing remains a separate, explicit choice.

Reduce unnecessary context by scoping queries, batching independent searches, reusing line-numbered source, and reading progressively instead of repeatedly loading entire files. Compare representative tasks only when measurement is permitted and feasible; report task selection, setup and tool costs, context-measurement limits, and observed results. Do not claim savings without evidence.
