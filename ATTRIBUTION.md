# Attribution

The current skills (verify, ui-check, and context), the verify hook, and the reviewer role were written for this repository. Their design follows published evaluations of coding-agent skills and harnesses; the README lists the main sources. No source text, scripts, or assets from those studies are included.

Earlier releases of this repository included skills whose structure and workflow ideas were informed by these projects. Those skills have been removed:

- [Caveman Codex](https://github.com/yibie/caveman-codex), licensed under [MIT](https://github.com/yibie/caveman-codex/blob/main/LICENSE).
- [Everything Claude Code (ECC)](https://github.com/affaan-m/ECC), licensed under [MIT](https://github.com/affaan-m/ECC/blob/main/LICENSE).
- For the former interface design skill: [Awesome Design Skills](https://github.com/bergside/awesome-design-skills), [Hallmark](https://github.com/Nutlope/hallmark), [Apple Design Skill](https://github.com/dickwu/apple-design-skill), [Anthropic Frontend Design](https://github.com/anthropics/skills/tree/main/skills/frontend-design), and [Impeccable](https://github.com/pbakaus/impeccable).
- For the former focused-solutions skill: [Ponytail](https://github.com/DietrichGebert/ponytail) by Dietrich Gebert, licensed under MIT. Its notice shipped with that skill.
